# Погодный дайджест

Консольная утилита на Node.js для получения прогноза погоды по одному или нескольким городам с использованием публичного API Open-Meteo.

Приложение выполняет геокодирование города, получает прогноз погоды, выводит результат в консоль и сохраняет его в JSON-файл. Для повторных запросов используется кэш текущего дня.

## Возможности

- поиск города по названию;
- получение прогноза погоды на 1–7 дней;
- обработка нескольких городов;
- параллельная обработка городов;
- сохранение отчётов в JSON;
- кэширование отчётов текущего дня;
- принудительное обновление через `--no-cache`;
- обработка ошибок API и сетевых ошибок;
- таймаут запросов;
- настройка параметров через `.env`.

## Требования

- Node.js 20 или выше;
- npm.

В проекте используется встроенный `fetch`, поэтому дополнительная библиотека для HTTP-запросов не требуется.

## Установка

Клонировать репозиторий:

git clone https://github.com/DashaMiMiheeva/weather-digest.git

Перейти в папку проекта:

cd weather-digest

Установить зависимости:

npm install

Создать файл .env на основе .env.example:

cp .env.example .env

Запустить приложение:

npm start -- --city "Москва" --days 3

## Переменные окружения

Основные настройки приложения задаются в файле `.env`.

| Переменная | Описание | Значение по умолчанию |
|---|---|---|
| `GEOCODING_BASE_URL` | URL API геокодирования | `https://geocoding-api.open-meteo.com/v1/search` |
| `FORECAST_BASE_URL` | URL API прогноза погоды | `https://api.open-meteo.com/v1/forecast` |
| `REQUEST_TIMEOUT` | Таймаут HTTP-запроса в миллисекундах | `5000` |
| `REPORTS_DIR` | Директория для сохранения отчётов | `reports` |
| `TEMPERATURE_UNIT` | Единица измерения температуры | `celsius` |
| `PRECIPITATION_UNIT` | Единица измерения осадков | `mm` |
| `LANGUAGE` | Язык поиска города | `ru` |

Пример файла `.env`:

GEOCODING_BASE_URL=https://geocoding-api.open-meteo.com/v1/search
FORECAST_BASE_URL=https://api.open-meteo.com/v1/forecast
REQUEST_TIMEOUT=5000
REPORTS_DIR=reports
TEMPERATURE_UNIT=celsius
PRECIPITATION_UNIT=mm
LANGUAGE=ru

Файл .env не добавляется в Git. Для примера конфигурации используется .env.example.

## Запуск

Основная команда:

npm start -- --city "Нижний Новгород" --days 3

Параметры
--city — обязательный параметр. Название одного города или нескольких городов через запятую.
--days — количество дней прогноза от 1 до 7. По умолчанию используется 3 дня.
--no-cache — принудительно получить актуальные данные из API, игнорируя сохранённый отчёт.
Примеры

Получить прогноз на 3 дня:

npm start -- --city "Москва"

Получить прогноз на 5 дней:

npm start -- --city "Москва" --days 5

Получить прогноз для нескольких городов:

npm start -- --city "Москва, Санкт-Петербург, Казань" --days 3

Принудительно обновить данные:

npm start -- --city "Москва" --days 3 --no-cache

## Кэширование

После получения прогноза отчёт сохраняется в директории `reports/` в формате JSON.

Имя файла формируется по шаблону:

{город}-{ГГГГ-ММ-ДД}.json

Для принудительного получения новых данных используется параметр:

npm start -- --city "Москва" --days 3 --no-cache

При использовании --no-cache сохранённый отчёт игнорируется, и данные повторно запрашиваются через API.

## Обработка ошибок

Приложение обрабатывает следующие ситуации:

- отсутствует обязательный параметр `--city`;
- указан неизвестный аргумент;
- не указано значение после `--city` или `--days`;
- значение `--days` не является целым числом от 1 до 7;
- город не найден;
- ошибка клиента HTTP 4xx;
- ошибка сервера HTTP 5xx;
- отсутствие подключения к серверу;
- превышение времени ожидания запроса;
- некорректный JSON в ответе сервера;
- некорректная структура данных прогноза.

При обработке нескольких городов ошибка одного города не останавливает получение данных для остальных.

Ошибки выводятся в консоль с указанием города и причины ошибки.

## Коды завершения

- `0` — выполнение завершено успешно;
- `1` — произошла ошибка при выполнении программы.

При обработке нескольких городов программа может успешно получить данные для части городов, но если хотя бы один город завершился с ошибкой, код завершения будет `1`.
